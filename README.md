# Luxury Tech

Next.js public website plus private offers, configurable commitment pricing and private-link digital agreement signing without customer login or email codes.

- `npm ci`
- `npm run dev` (port 8080)
- `npm run build` / `npm start`
- `npm test`, `npm run typecheck`, `npm run lint`, `npm run test:e2e`

See [OFFERS.md](OFFERS.md) for Vercel deployment, MongoDB, environment variables, admin access, customer flow, legal approval and notification setup. Use [.env.example](.env.example) as the server-only configuration reference. Never commit credentials.
